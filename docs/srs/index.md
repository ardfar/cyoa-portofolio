## What This Project Is

A personal portfolio website for **Farras Arrafi** built on the **"Choose Your Own Adventure"** concept. Visitors select a persona — Technology, Management, or Creative — and the site adapts all content accordingly.

### The Problem It Solves

A traditional portfolio overwhelms visitors with irrelevant content. A tech recruiter doesn't need to see photography. A creative client doesn't need to read about Docker deployments.

The CYOA model makes the **visitor's context the first input** before any content is shown.

### Rebuild Goals

| # | Goal |
|---|---|
| 1 | **Visual/UX overhaul** — high-end agency aesthetic |
| 2 | **Content editability** — protected admin panel with full CRUD |
| 3 | **SEO performance** — persona-routed pages, meta, structured data |
